* Utility classes for working with players, worlds, commands and chat.
* Item delivery, counting and removal, with support for comparing item metadata and data components.
* Item parsing and serialization, including helpers for migrating legacy item data.
* Text formatting with legacy and HEX colors, clickable messages and hover text.
* Server tick timers with delays, repeat intervals, limited or infinite iterations and cancellation.
* Scheduled resets with configurable periods and time zones.
* YAML and JSON configuration loaders with default values, custom serializers and asynchronous saving.
* Ordered configuration writes, optional backups for malformed files and pending-save flushing on server shutdown.
* Database connection pools for MySQL, MariaDB and PostgreSQL, powered by HikariCP, with asynchronous task helpers.
* UI module for creating server-side inventory menus with click callbacks, redirected slots and deferred opening (forked from [SGui](https://github.com/Patbox/sgui)).
* GUI item builders for custom names, lore, enchantments, player heads and CustomModelData.
* Permission helpers for online and offline players, with LuckPerms integration and numeric permission limits.
* Packet helpers for sending data to individual players, all players or players in a specific dimension.
* Client-side screen scaling helpers for consistent UI layouts.
* Dedicated Forge, NeoForge and Fabric builds for supported Minecraft versions.
